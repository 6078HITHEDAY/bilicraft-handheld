## 登录相关

### 登录时打不开浏览器 / 没有跳转

设备码流程需要浏览器，App 只会调起系统默认浏览器。若没有跳转，可手动打开浏览器访问页面上显示的地址（通常是 `https://microsoft.com/link`），再手动输入屏幕上的设备码。

### 设备码过期 / 提示授权失败

设备码有时效限制。授权失败或过期时，回到 App 点「返回主界面」取消本次登录，再重新点「使用微软账户登录」获取新设备码即可。

### 登录一直卡在「正在获取游戏令牌…」

这一步在向微软换取 XBL / XSTS / Minecraft Token，依赖网络。请确认：

- 能正常访问微软服务（`login.live.com`、`xsts.auth.xboxlive.com`、Minecraft 认证接口）。
- 没有代理/防火墙拦截上述域名。
- 若长时间卡住，取消后重试一次。

### 登录后能保存多久？需要重新登录吗？

凭证加密保存在本机（`EncryptedSharedPreferences`，AES-256-GCM），`refresh_token` 会静默刷新。只要不主动「退出全部」、不卸载应用、不清除应用数据，通常无需重复登录。

### 这个 App 安全吗？会不会泄露密码？

登录采用**设备码流程**，你**不向 App 输入密码**，密码只在微软官方页面输入。App 保存的是令牌而非密码，且加密落盘，永不明文存储。

## 连接服务器相关

### 连不上服务器，一直显示连接失败 / 超时

按顺序排查：

1. **服务器是否在线**：先用电脑版 Minecraft 或其他工具确认服务器可连。
2. **地址与端口**：确认频道里的服务器地址、端口正确（默认 `25565`）。
3. **版本不匹配**：先试「自动识别」；若服务器版本特殊，手动选择对应版本。
4. **网络**：确认手机能访问该服务器（校园网/公司网/部分运营商可能屏蔽特定端口）。
5. **白名单/正版校验**：若服务器开了白名单或正版校验，需你的游戏 ID 在名单内、且登录的是对应正版账号。

### 提示版本不匹配 / 协议不符

App 内置协议表覆盖 1.7.10 至 26.2。极新或极旧的快照版可能不在映射内，尝试：

- 版本选「自动识别」。
- 「设置 → 版本数据 → 刷新版本列表」，再重连。
- 「设置 → 版本数据 → 清除版本缓存」后重连。

### 服务器要求「强制安全档案」，我无法发言

这通常意味着服务器开启了 `enforce-secure-profile=true`。请在**编辑频道**里打开「**强制签名聊天**」开关后重新连接。

> 注意：该功能仅支持 1.19.3（协议 761）及以上的 session 签名体系；更老版本的强制签名服可能回退为未签名，无法完全兼容。

### 我能进服务器但收不到/发不出消息

- 确认你已进入服务器并在线（查看频道信息条的状态与在线人数）。
- 若服务器聊天格式特殊，尝试在**编辑频道 → 高级 → 解析规则**里切换「碧玺」或「自定义正则」。
- 部分服务器会因聊天签名问题丢弃未签名消息，尝试开启「强制签名聊天」。

### 支持哪些服务器版本？

支持 Minecraft Java 版 1.7.10 至 26.2 的聊天收发。较新版本（1.20.2 之后的 configuration 阶段）已兼容；极老版本建议配合「自动识别」。

## 聊天与私聊相关

### 私聊没有正确分到对应玩家页

App 自动识别常见私聊格式（`messages you:`、`/msg`、`/tell`、`/w`、中英文 whisper 等）。若服务器使用了特殊插件格式，可能无法识别，此时私聊内容会留在公屏或归错人。这属于解析限制，可尝试：

- 确认对方的私聊回显格式是否被支持（常见 `messages you: 正文` 已支持）。
- 服务器格式特殊时，暂无法完美分流，可关注后续版本对更多格式的适配。

### 消息太多，历史被截断了？

每频道本地聊天记录有上限（默认条数可在「设置 → 聊天显示 → 聊天记录上限」调整）。超出上限的旧消息会被滚动淘汰，这是为控制内存/存储的有意设计。

### 如何清空某个频道的聊天记录？

在「聊天」页长按该频道 →「清空聊天」。

### 快捷回复怎么用？

「设置 → 聊天显示 → 快捷回复」里每行写一条短语（最多 12 条）。在聊天输入栏点「短语」即可快速选择发送。

### 命令补全是什么？

在输入框输入 `/` 开头的命令时，App 会向服务器请求候选项（如玩家名、子命令）。可在「设置 → 聊天显示 → 命令补全」开关。

## 后台保活

### 锁屏 / 切后台后掉线

这是国内厂商系统最常见的现象。请按顺序处理：

1. 「设置 → 后台保活 → 忽略电池优化」并授权。
2. 「设置 → 后台保活 → 厂商后台限制指引」按你的品牌放行。
3. 在最近任务列表给本应用**加锁**，防止一键清理。
4. 若仍频繁掉线，可**关闭**「低能耗挂后台」（该模式为省电主动降低保活强度）。

各厂商参考路径（系统菜单名可能随版本变化）：

| 品牌 | 路径 |
| --- | --- |
| 小米 / Redmi（HyperOS、MIUI） | 设置 → 应用设置 → 应用管理 → 掌上碧玺 → 开启「自启动」，「省电策略」改为「无限制」 |
| 华为（HarmonyOS、EMUI） | 设置 → 应用和服务 → 应用启动管理 → 掌上碧玺 → 关闭自动管理，允许「后台活动」 |
| 荣耀（MagicOS） | 设置 → 应用和服务 → 应用启动管理 → 掌上碧玺 → 关闭自动管理，允许「自启动」与「关联启动」 |
| OPPO / 一加 / realme（ColorOS） | 设置 → 电池 → 应用耗电管理 → 掌上碧玺 → 允许「后台运行」与「自启动」 |
| vivo / iQOO（OriginOS、Funtouch） | 设置 → 电池 → 后台耗电管理 → 掌上碧玺 → 允许「后台高耗电」，应用管理里开启自启动 |
| 三星（One UI） | 设置 → 电池 → 后台使用限制 → 把掌上碧玺加入「从不休眠的应用」 |

### 「低能耗挂后台」是什么？要开吗？

- **开**：退后台/息屏后释放唤醒锁、降低通知刷新频率，更省电，但掉线概率略增（掉线后仍会自动重连）。
- **关**（默认）：保活更稳，相对耗电。

追求稳定挂机建议保持关闭；追求省电、可接受偶发掉线再打开。

### 掉线后会自动重连吗？

会。连接参数会落盘，进程被回收、网络恢复后都会自动重连，无需手动操作。

## 更新相关

### 提示「更新失败」/ 下载失败

- 先到「设置 → 关于 → 下载线路」切换到备用线路或直连。
- 确认网络能访问对应下载源。
- 若系统提示「安装未知来源应用」，请允许后再安装。

### 提示无法安装 / 覆盖失败 / 签名不一致

应用内更新要求**新旧包签名一致**。若你之前装的是不同签名来源的包（例如换过渠道），系统会拒绝覆盖安装。此时需卸载旧版再安装新版（注意：卸载会清空本地登录与数据，请先确认没有重要本地记录）。

### 更新会丢数据吗？

正常覆盖安装不会丢数据（登录凭证、频道、插件等都在）。但若因签名不一致而卸载重装，则会清空本地数据。

### 「检查更新」显示的公告和 GitHub 上的不一样？

App 内只展示维护者**手写在 Release 顶部、面向玩家**的那段公告，不展示 GitHub 自动生成的 commit/PR 列表。这是有意设计。

## 插件相关

### 插件在哪里管理？

「设置 → 插件管理」：上方是「已安装插件」（导入、启停、卸载、重新扫描），下方是「官方插件市场」（安装、更新）。

### 如何导入一个 `.bhplugin` 插件？

两种方式：

1. 点「导入插件包」，从文件管理器选择 `.bhplugin` 文件。
2. 把 `.bhplugin` 放入「插件目录」显示的路径，再点「重新扫描」。

### 装好的插件在哪里打开？

插件启用后，进入任意**频道会话页**，点屏幕**右侧边缘**的折叠「插件入口」面板，从列表进入具体插件页面。

### 插件显示「加载失败」？

可能是插件包损坏、API 版本不兼容或插件自身异常。可尝试：

- 确认 `.bhplugin` 文件完整、来源可信。
- 从官方市场重新安装（官方源插件会校验 SHA-256）。
- 检查插件是否声明了本应用不支持的 API 版本。

### 官方市场插件「不兼容」？

表示该插件要求的最低 App 版本或 API 版本高于你当前安装的版本。请先在「关于 → 检查更新」把应用升级到最新版。

### 官方市场刷新失败？

刷新失败时会保留本地缓存，稍后重试。若长期失败，可能是网络无法访问官方源，可尝试切换网络或代理。

## 外观与图标

### 切换启动图标后，桌面图标不见了？

这是系统机制：切换图标后桌面图标会短暂消失再重现，部分系统会把应用从最近任务清除。稍等片刻或回桌面查看即可；属正常现象。

### 支持哪些主题？

跟随系统 / 浅色 / 深色，在「设置 → 外观 → 主题」选择。

### 聊天字号、记录上限怎么调？

「设置 → 聊天显示」里分别有「聊天字号」和「聊天记录上限」。

## 其他

### 应用显示名为什么叫「掌上碧玺」？

「掌上碧玺」是 Bilicraft Handheld 的中文显示名（安装后桌面的应用名），两者指同一应用。

### 支持基岩版（Bedrock）服务器吗？

不支持。本项目只连接 **Minecraft Java 版**服务器（Netty 手写 Java 协议栈）。

### 支持 Bedrock 客户端吗？能玩吗？

本项目是**聊天客户端**，不是游戏本体：它用来在手机上收发服务器聊天，不能进入 3D 世界游玩。想真正游玩仍需要 Minecraft 本体。

### 我在哪反馈问题 / 提交建议？

到项目 GitHub 仓库提 Issue。仓库地址见 [README](../README.md) 顶部的链接。

### 隐私说明

- 登录凭证、频道、聊天记录、插件等都保存在**手机本地**。
- 无云端 Core；插件市场、CDK、版本清单、更新检查只访问官方配置的远程地址。
- 微软登录只在你主动登录时发生，且密码不经 App。
