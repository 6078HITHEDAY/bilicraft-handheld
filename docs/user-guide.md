# 用户手册 · 掌上碧玺

本文是「掌上碧玺」（Bilicraft Handheld）的完整使用指南，面向玩家。内容按使用顺序组织：登录 → 连接服务器 → 群聊 → 私聊 → 设置 → 插件 → CDK → 更新与后台保活。

> 一句话理解：这是一个**在手机上收发 Minecraft Java 版聊天**的客户端。你把服务器加为「频道」，就能像用 Telegram 一样群聊、私聊，还能装插件扩展功能。

## 1. 登录微软账户

掌上碧玺使用 **微软设备码流程**登录，**全程不需要输入密码**。

1. 打开 App，在登录页点击「**使用微软账户登录**」。
2. 稍等片刻，页面会显示一个**大号设备码**（例如 `ABCD-EFGH`），并自动复制到剪贴板。
3. 点击「**打开浏览器**」（或手动访问页面上显示的链接，通常是 `https://microsoft.com/link`）。
4. 在微软页面粘贴/输入设备码，选择你的微软账户并授权。
5. 授权完成后回到 App，等待片刻即可自动登录成功。

登录成功后，App 会进入主界面。之后无需重复登录：`refresh_token` 会在后台静默刷新，你无感知。

> 常见登录问题（设备码过期、打不开浏览器、登录卡住等）见 [常见问题](faq.md#登录相关)。

### 多账号

设置页「账号管理」支持添加多个账号，并可在它们之间切换：

- **添加账号**：再走一次上面的设备码流程。
- **切换到某账号**：在账号列表点击该账号（或点右侧切换按钮）。
- **移除账号**：长按该账号，或点右侧删除按钮，确认后本地登录凭证会被删除。
- **刷新 Token**：手动刷新当前账号的令牌。
- **退出全部**：清空所有账号的登录状态。

## 2. 认识主界面

主界面底部有三个 Tab，均为顶部导航：

| Tab | 作用 |
| --- | --- |
| **聊天** | 服务器即「频道」列表，点进去群聊；右上角可新增频道、完全退出 |
| **联系人** | 展示服务器在线玩家名单与像素头像，点玩家私聊 |
| **设置** | 账号、插件、聊天显示、后台保活、外观、CDK、版本与关于 |

- 聊天 Tab 图标上有**红色角标**时，表示有未读消息；设置 Tab 图标有角标时，表示官方插件有可更新版本。
- 宽屏设备（如平板、折叠屏展开态）会自动切换为**双栏布局**：左侧是列表，右侧是聊天/私聊详情。

## 3. 连接服务器（频道）

在「聊天」页右上角点击「**＋**」新增频道，填写以下信息：

| 字段 | 说明 |
| --- | --- |
| **名称** | 频道显示名，可随意填；留空则自动用服务器地址 |
| **服务器地址** | Minecraft Java 服务器地址，例如 `play.example.com` 或 IP |
| **端口** | 默认 `25565`，一般不用改 |
| **MC 版本** | 默认「自动识别」。也可手动选择：最新版 / Release / Snapshot / Old Alpha·Beta |
| **强制签名聊天** | 默认关闭。连接要求「强制安全档案」的正版服务器时才需开启 |
| **高级 → 解析规则** | 聊天内容解析规则，见下文 |

填写后点「保存」，频道即出现在聊天列表。点进频道，在顶部信息条点击「**连接**」即可连入服务器。

### MC 版本怎么选

- 绝大多数情况保持「**自动识别**」即可，App 会先用服务器 ping 自动探测版本，失败时回退到内置映射。
- 只有自动识别失败、且你明确知道服务器版本时，才手动指定版本。
- 版本下拉框分组展示：自动识别（置顶）→ 最新版 → Release → Snapshot → Old Alpha/Beta。

### 强制签名聊天

- 普通服务器（离线服、未开启 `enforce-secure-profile` 的正版服）保持**关闭**即可。
- 仅当服务器开启了「强制安全档案 / 强制聊天签名」导致你无法正常发言时，才开启。
- 开启后 App 会取 Mojang 玩家证书并对每条聊天做真实签名；私钥只在内存中使用，不落盘。
- 注意：该功能仅支持 1.19.3（协议 761）及以上的 session 签名体系，旧版本服即使开启也可能回退为未签名。

### 解析规则（高级）

用于从服务器公屏拆出子服名、玩家、称号、阵营等信息，主要面向碧玺多服结构：

- **原版（`<玩家> 正文`）**：标准 Minecraft 聊天格式。
- **碧玺（阵营+称号+玩家+正文）**：适配碧玺服务器的子服标签（如 `HY`）。
- **自定义正则**：自行编写正则，可用命名组 `(?<server>)`、`(?<player>)`、`(?<message>)`、`(?<title>)`、`(?<faction>)`。

普通服务器保持「原版」即可。

## 4. 群聊

进入频道后，界面自上而下：

- **顶栏**：返回、连接状态圆点、频道名与在线人数、搜索、成员、复活、编辑。
- **信息条**：显示 `地址:端口 · 版本`，若开启强制签名会显示 🔒「强制签名」；右侧「连接 / 断开」按钮。
- **成员横条**：一排在线玩家的头像，点任意头像可直接私聊。
- **聊天气泡区**：按时间排列的消息。
- **输入栏**：输入文字回车/发送；支持命令补全与快捷回复。

### 聊天气泡

- **自己**的消息与**他人**的消息分左右显示。
- **系统消息**（进出服、死亡、成就等）单独呈现，不会和聊天混在一起。
- 打开频道时会显示一条**未读分隔线**，方便区分新消息与历史消息。

### 常用操作

| 操作 | 方法 |
| --- | --- |
| 搜索本频道消息 | 点顶栏放大镜图标，输入关键词 |
| 查看群成员 | 点顶栏成员图标（或点标题栏） |
| 复活 | 连接状态下点顶栏「❤」按钮（发送重生/复活动作） |
| 转发消息到其他频道 | 长按某条消息 → 选择目标频道（目标频道需已连接） |
| 删除本地消息 | 长按消息 → 删除本地记录 |
| 编辑频道 | 点顶栏编辑图标 |
| 发送命令 | 输入 `/` 开头的内容，可开启命令补全 |

### 频道列表的更多操作

在「聊天」页**长按**某个频道，可弹出菜单：

- **置顶 / 取消置顶**：置顶的频道排在最前并显示 📌。
- **归档 / 取消归档**：归档的频道移到列表末尾并标注「已归档」。
- **清空聊天**：清空该频道的本地聊天记录。
- **复制地址**：复制 `地址:端口` 到剪贴板。
- **编辑**：修改频道的名称、地址、版本、签名、解析规则等。
- **删除**：移除该频道。

### 完全退出

「聊天」页右上角的电源图标 = **完全退出**。它会断开连接、清理通知并彻底退出后台，不留后台进程。平时只是返回桌面不会退出，连接会继续在后台保持。

## 5. 私聊与联系人

### 联系人页

「联系人」Tab 展示服务器玩家名单：

- **自动同步**：连接频道后，会自动把服务器 Tab 名单中的在线玩家显示为联系人。
- **手动添加**：右上角「＋」，填玩家名（必填）和备注（可选），并选择所属服务器。
- **像素头像**：基于玩家名生成；在线玩家显示在线状态与延迟（ms）。
- **搜索**：顶部可搜索玩家名或备注。
- **分组**：「按服务器分组」开关控制是否按服务器分节展示；关闭后可选择「主服务器」只看单个服务器的联系人。

点任意联系人进入**私聊页**；长按联系人可「打开私聊 / 编辑备注 / 移除」。

### 私聊识别

App 会自动识别并分流私聊，公屏不再混入私聊内容。常见入站格式（如 `messages you: 正文`）会自动归入对应玩家的私聊页；`/msg`、`/tell`、`/w` 等命令的回显也会被识别。

> 若某些私聊没有被正确识别到某个玩家，可能是服务器聊天格式特殊。详见 [常见问题](faq.md#私聊相关)。

## 6. 设置页详解

设置页按模块分区，以下是各分区说明。

### 账号管理

添加账号、切换账号、移除账号、刷新 Token、退出全部。见 [第 1 节](#1-登录微软账户)。

### 插件

「插件管理」入口，见 [第 7 节](#7-插件)。

### 聊天显示

| 设置 | 说明 |
| --- | --- |
| **自动滚动到最新聊天** | 关闭后，新消息不会打断你查看历史 |
| **命令补全** | 输入 `/` 命令时向服务器请求候选项 |
| **快捷回复** | 配置常用短语（每行一条），输入栏「短语」可快速发送 |
| **聊天字号** | 小(90%) / 标准(100%) / 大(115%) / 更大(130%) |
| **聊天记录上限** | 每频道本地保留的消息条数 |

### 后台保活

见 [第 10 节](#10-后台保活与省电)。

### 外观

| 设置 | 说明 |
| --- | --- |
| **主题** | 跟随系统 / 浅色 / 深色 |
| **启动图标** | 替换桌面启动图标 |
| **通知点击** | 点通知时打开主页，或直接打开对应频道 |

> 切换启动图标后，桌面图标可能短暂消失再重现，部分系统会把应用从最近任务清除，属正常现象。

### 版本数据

- **刷新版本列表**：重新拉取 Minecraft 版本元数据。
- **清除版本缓存**：清空本地缓存的版本清单，下次连接时重新拉取。

### 关于

- **检查更新**：手动检查并下载新版本，见 [第 9 节](#9-检查更新)。
- **下载线路**：切换更新下载线路（默认「加速线路 · 推荐」）。
- **包名**：当前安装包名（`com.bilicraft.handheld`）。
- **插件目录**：外部插件存放目录，用于手动放入 `.bhplugin` 文件。

## 7. 插件

插件入口在**设置 → 插件管理**。

### 已安装插件

- **插件目录**：显示 `.bhplugin` 的存放路径；可手动把插件包放入该目录后点「重新扫描」。
- **导入插件包**：从文件管理器选择 `.bhplugin` 文件导入。
- **重新扫描**：重新读取插件目录。
- 每个已装插件可**启用/禁用**（开关）或**移除**（垃圾桶图标）。

### 官方插件市场

- **官方精选**：经过官方审核的插件，安全可靠；点刷新按钮拉取最新索引。
- 每个插件显示名称、版本、作者、简介、大小、权限和更新说明，并提供「安装 / 更新 / 已安装 / 不兼容」按钮。
- 官方市场插件安装时会自动校验 SHA-256 与插件清单，确保来源可信。

### 打开插件页面

插件启用后，进入任意**频道会话页**，点屏幕**右侧边缘**的折叠「插件入口」面板，从候选列表进入具体插件页面。部分插件可能需要先连接服务器才能正常工作。

> 插件的开发与发布方式（面向开发者）见 [插件开发与官方插件源](plugin-development.md)。

## 8. CDK 兑换码

设置页的「**CDK 兑换码**」卡片会展示官方在活动期间发放的兑换码：

- 卡片只显示**当前时间在有效期内的** CDK（按 `startsAt` / `endsAt` 过滤）。
- 点条目右侧「**复制**」即可复制 CDK 到剪贴板，随后到对应场景兑换。
- 无有效 CDK 时显示空状态；可点右上角刷新按钮手动刷新。

## 9. 检查更新

设置 → 关于 →「检查更新」，App 会查询最新版本：

- 有新版本时弹窗展示**更新内容**（面向玩家的公告），点「下载」下载 APK。
- 下载完成后点「安装」覆盖安装。
- 更新前请确认：**新旧包签名必须一致**，否则系统会拒绝覆盖安装；若系统提示，请允许「安装未知来源应用」。

> 下载线路默认走国内加速线路。若下载失败，可在「下载线路」里切换到备用线路或直连。

## 10. 后台保活与省电

掌上碧玺通过前台服务在**锁屏 / 切后台后继续保持连接**，掉线会自动重连。为让它更稳定地挂后台，设置页「后台保活」提供：

| 设置 | 说明 |
| --- | --- |
| **低能耗挂后台** | 退到后台或息屏后释放唤醒锁、降低通知刷新频率，更省电；掉线概率略增，但仍会自动重连 |
| **忽略电池优化** | 引导你给本应用授权，减少系统息屏后清理后台连接的情况 |
| **厂商后台限制指引** | 列出小米、华为、荣耀、OPPO、vivo、三星等系统放行后台的路径，并可一键跳转应用详情页 |

**建议做法**（想让后台最稳）：

1. 点「忽略电池优化」并授权。
2. 点「厂商后台限制指引」，按你的手机品牌对应路径开启自启动 / 后台运行 / 允许后台活动。
3. 在最近任务列表里给本应用**加锁**，避免一键清理时被关掉。
4. 若更在意省电、可接受偶发掉线，再打开「低能耗挂后台」。

> 各厂商后台管控的具体路径见 [常见问题](faq.md#后台保活) 或设置页内的「厂商后台限制指引」。
