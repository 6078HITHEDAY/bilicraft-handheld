## 快速上手（30 秒版）

1. **登录**：打开 App →「使用微软账户登录」→ 在浏览器打开 `https://microsoft.com/link` 输入屏幕上显示的设备码 → 授权完成回到 App。
2. **连服务器**：「聊天」页右上角「＋」新增频道 → 填服务器地址、端口，版本保持「自动识别」→ 保存 → 点「连接」。
3. **群聊**：在频道里直接发消息；「联系人」页点任意玩家即可私聊。

完整步骤与各项设置说明见 [用户手册](user-guide.md)。
